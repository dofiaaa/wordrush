# Геймдизайн и экономика — СловоВойна

## 1. Концепция

Слова — уникальные активы, как доменные имена. Игрок крутит рулетку, получает слово,
владеет им, продаёт, покупает и обменивается на рынке. Цель — собрать ценный портфель.

## 2. Модель ценности (ключевая инверсия)

- Ценность слова определяет **спрос**, а не лингвистическая редкость.
- Частые и желанные слова («пицца», «деньги», «любовь») дороже редких нишевых («наукоград»).
- Частотность даёт только стартовую оценку `est_value` (лог-шкала, 5..1000).
- Реальную цену ставит рынок: продажи, аукционы, обмены.

## 3. Выпадение (рулетка)

- **Равные шансы**: любое невыбитое слово выпадает с одинаковой вероятностью.
- Тир редкости — косметический «стат» карточки, на выпадение и цену НЕ влияет.
- Спины бесплатные, ограничены перезарядкой по времени (`SPIN_COOLDOWN_MS`).

## 4. Уникальность и пул

- Каждое слово — один экземпляр (уникальное владение).
- Словарь конечен, поэтому пул пополняется:
  - **Аренда**: просроченное слово возвращается в пул (30 дней).
  - **Волны новых слов**: периодический выпуск (неологизмы, города, сленг).

## 5. Экономика (без донатов)

| Параметр | Значение | Роль |
| --- | --- | --- |
| Ежедневный бонус | 50 монет | кран |
| Награда за спин | 10 монет | кран |
| Комиссия рынка | 5% | сток |
| Продление аренды | 20 монет / 30 дней | сток |

Без крана монет неоткуда взяться, без стока — инфляция.

## 6. Рынок

- **Продажа** — фиксированная цена.
- **Аукцион** — ставки; покупка по максимальной ставке или мгновенный выкуп.
- **Обмен** — бартер 1-на-1: открытое предложение или адресованное конкретному игроку.
- Все сделки — атомарные серверные транзакции (перевод монет ⇄ смена владельца).

## 7. Топ

Капитал аккаунта = сумма `est_value` слов в коллекции. Топ — по капиталу.

## 8. Схема слова (words.json)

```json
{
  "id": "пицца",
  "lemma": "пицца",
  "pos": "сущ",
  "frequency_ipm": 38.4,
  "rarity_tier": "common",
  "est_value": 950,
  "definition": "...",
  "examples": ["..."]
}
```

## 9. Архитектура

- `:core` — чистая Kotlin-логика (GameEngine, Econ, Market, Word). Без Android.
- `:app` — Compose UI + in-memory репозиторий (сейчас), позже — сетевой.
- Сервер — авторитетное владение, экономика, топ (см. API.md).

## 10. Античит

Владение, монеты, сделки — только на сервере. Клиент лишь отображает состояние.
