# СловоВойна (wordrush)

Коллекционная Android-игра про слова русского языка: крути рулетку, собирай слова,
торгуй и обменивайся ими. Ценность слова — как у доменов: частые и желанные слова
(«пицца», «деньги», «любовь») дороже редких нишевых («наукоград»).

Без донатов: спины бесплатные, монеты зарабатываются игрой, цену ставит рынок.

## Принятые решения

- Выпадение — равновероятное (рулетка выбирает любое невыбитое слово с равным шансом).
- Уникальность — каждое слово существует в одном экземпляре (как домен).
- Аренда — слово нужно продлевать за монеты; просроченное возвращается в пул.
- Ценность — частота даёт стартовую оценку est_value, реальную цену ставит P2P-рынок.
- Рынок — продажа (фикс. цена), аукцион, обмен (бартер 1-на-1).
- Топ — по капиталу портфеля (сумма est_value слов).
- Android 6.0+ (minSdk 23), Kotlin + Jetpack Compose.

## Структура проекта

    wordrush/
      core/                 чистая Kotlin-логика (переносится на iOS)
      app/                  Android-приложение (Jetpack Compose, UI)
      tools/build_dictionary.py      демо-словарь (154 слова с определениями)
      tools/import_frequency.py      импорт реального частотного списка
      app/src/main/assets/words.json словарь (30 000 слов)
      docs/DESIGN.md        геймдизайн и экономика
      docs/API.md           контракт сервера

## Сборка

1. Откройте папку wordrush в Android Studio (Gradle 8.7, AGP 8.5.2, Kotlin 1.9.24).
2. Запустите на эмуляторе/устройстве с Android 6.0+ (API 23+).

Из командной строки (нужен установленный Gradle):

    cd wordrush
    gradle wrapper --gradle-version 8.7
    ./gradlew :app:assembleDebug

APK собирается автоматически в GitHub Actions при пуше в main (workflow build-apk.yml).

## Словарь

Подключён боевой словарь — 30 000 слов из частотного списка OpenSubtitles,
с оценкой стоимости по реальной частоте употребления.

Источник (CC BY-SA 4.0, укажите атрибуцию):

- OpenSubtitles FrequencyWords — https://github.com/hermitdave/FrequencyWords

Пересборка словаря:

    cd wordrush
    curl -fsSL "https://raw.githubusercontent.com/hermitdave/FrequencyWords/master/content/2018/ru/ru_50k.txt" -o /tmp/ru_50k.txt
    python3 tools/import_frequency.py /tmp/ru_50k.txt app/src/main/assets/words.json --limit 30000

Демо-словарь с определениями: python3 tools/build_dictionary.py

Известные ограничения (роадмап):

- слова — словоформы, не леммы («дом», «дома», «дому» — разные карточки); нужна лемматизация;
- определения и части речи заполнены только для ~20 частых слов; нужен импорт из Викисловаря;
- словарь (4 МБ) грузится на главном потоке; нужен фоновый парсинг.

## Дорожная карта

1. Ядро + офлайн-прототип (готово).
2. Боевой словарь из частотного списка (готово).
3. Сервер (docs/API.md): аккаунты, владение, рынок, топ.
4. Лемматизация и определения из Викисловаря.
5. Порт на iOS через Kotlin Multiplatform.

## Порт на iOS

Вся логика лежит в чистом модуле :core без Android-зависимостей. Для iOS его
достаточно перенести в Kotlin Multiplatform commonMain и переиспользовать UI через
Compose Multiplatform.
