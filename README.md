# СловоВойна (wordrush)

Коллекционная Android-игра про слова русского языка: крути рулетку, собирай слова,
торгуй и обменивайся ими. Ценность слова — как у доменов: **частые и желанные слова
(«пицца», «деньги», «любовь») дороже редких и нишевых («наукоград»)**.

Без донатов: спины бесплатные, монеты зарабатываются игрой, цену ставит рынок.

## Принятые решения

- **Выпадение** — равновероятное (рулетка выбирает любое невыбитое слово с равным шансом).
- **Уникальность** — каждое слово существует в одном экземпляре (как домен).
- **Аренда** — слово нужно продлевать за монеты; просроченное возвращается в пул.
- **Ценность** — частота даёт лишь стартовую оценку `est_value`, реальную цену ставит P2P-рынок.
- **Рынок** — продажа (фикс. цена), аукцион, обмен (бартер 1-на-1).
- **Топ** — по капиталу портфеля (сумма `est_value` слов).
- **Android 6.0+** (minSdk 23), Kotlin + Jetpack Compose.

## Структура проекта

```
wordrush/
  core/                 чистый Kotlin-модуль: вся игровая логика (переносится на iOS)
  app/                  Android-приложение (Jetpack Compose, UI)
  tools/build_dictionary.py   генератор словаря из частотного списка
  app/src/main/assets/words.json   словарь (демо-версия)
  docs/DESIGN.md        полный геймдизайн и экономика
  docs/API.md           контракт будущего сервера
```

## Сборка

1. Откройте папку `wordrush` в Android Studio (Gradle 8.7, AGP 8.5.2, Kotlin 1.9.24).
2. Запустите на эмуляторе/устройстве с Android 6.0+ (API 23+).

Из командной строки (нужен установленный Gradle):

```bash
cd wordrush
gradle wrapper --gradle-version 8.7   # один раз, чтобы появился gradlew
./gradlew :app:assembleDebug
```

## Словарь

Демо-словарь генерируется скриптом:

```bash
cd wordrush
python3 tools/build_dictionary.py                        # демо -> app/src/main/assets/words.json
python3 tools/build_dictionary.py freq.csv out.json      # реальный CSV (rank,word,ipm)
```

Для релиза подключите реальный частотный список (проверьте лицензии):

- OpenSubtitles — https://github.com/hermitdave/FrequencyWords
- Leipzig Corpora — https://wortschatz.uni-leipzig.de/
- ru.wiktionary.org — определения и примеры (CC BY-SA, нужна атрибуция)

## Порт на iOS

Вся логика лежит в чистом модуле `:core` без Android-зависимостей. Для iOS его
достаточно перенести в Kotlin Multiplatform `commonMain` и переиспользовать UI через
Compose Multiplatform — бизнес-правила переписывать не нужно.
